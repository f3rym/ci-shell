# История версий

Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — по [семантическому версионированию](https://semver.org/lang/ru/).

## [Не выпущено]

Готовится 1.0.0: восстановление артефактов предыдущих стадий и сплошное ревью кода.

### Добавлено

- Правка значения любой переменной прямо на экране джобы по `i` — не только
  незаполненной скрытой, как было раньше. Изменённое уезжает в контейнер тем же
  путём, что и остальное окружение, и переживает перезапуск шага и чистый прогон.
- Файл `.edit_vars` рядом с патчем работы: список переменных, которые человек менял
  за сессию. Значений в нём нет намеренно.
- Проект восстановления артефактов — `docs/artifacts-design.md`. Решения приняты,
  кода пока нет.

### Исправлено

- Ключ проекта в файле секретов сериализуется, а не склеивается строками. Хост с
  символами вроде `&` или `*` разбирался YAML как объявление якоря, и файл переставал
  читаться целиком — человек терял доступ к секретам всех остальных проектов.
- Маркеры секций лога распознаются по своей настоящей границе. Раньше вместе с
  маркером выбрасывался и склеенный с ним реальный вывод джобы.
- Маркеры шагов несут случайную метку прогона, поэтому вывод самой джобы больше не
  может притвориться маркером. Раньше подделка приводила к перезапуску не того шага.
- `Ctrl-C`, нажатый внутри шелла контейнера, больше не убивает всю сессию.
- Лог прошлой джобы проходит через маскировщик секретов, как и вывод живой сессии.
- Предопределённость переменной определяется именем, а не меткой источника.
  Переменная проекта, названная `CI_COMMIT_SHA`, отбирала у настоящей запись вместе
  с запретом на правку.
- Хост приводится к нижнему регистру в точке появления. Ссылки с `GitLab.Example.Com`
  и `gitlab.example.com` больше не дают разных ключей в файле токенов, файле секретов
  и путях кэша.

## [0.3.2]

Интерфейс перестаёт тратить экран впустую и начинает называть себя.

### Добавлено

- Стартовый экран во весь кадр с логотипом и подписью вместо текста в углу.
- Клик мышью по строке равен `⏎` на ней.

### Изменено

- Колонки делят кадр по содержимому, а не поровну: где мало строк — колонка ужимается,
  соседняя расширяется, пустого места не остаётся.
- Отработавшие левые колонки сворачиваются в узкую полосу и разворачиваются по `←`.
- `q` возвращает на шаг назад, а не выходит. Выход — `ctrl+c` или `:q`, и он
  по-прежнему убирает контейнер, чекаут и каталог материализованных секретов.
- Строка подсказки называет клавиши, доступные прямо сейчас, читая их из раскладки.

### Исправлено

- Содержимое колонки больше не выходит за её рамку, а колонки не расходятся по высоте.
- Заголовок таблицы пайплайнов не переносится на вторую строку.
- Логотип на стартовом экране центрируется вместе с остальным содержимым.

## [0.3.1]

Интерфейс, который не надо изучать.

### Добавлено

- Меню входа вместо пустого поля ввода: свои репозитории, открытие джобы по ссылке,
  добавление ключа. Несколько ключей становятся отдельными корнями дерева.
- Полноэкранный просмотрщик лога: прокрутка, поиск с подсветкой, переход к месту падения.
- Лог принадлежит шагу, а не джобе. `R` заменяет лог свежим, а не дописывает снизу.
- Заполнение незаполненной скрытой переменной прямо на экране джобы.
- Живой фоновый элемент, скрывающийся там, где мешает.

### Изменено

- Навигация стала лентой колонок: что глубже, то правее. `→` и `←` значат одно и то
  же на всех экранах, стек экранов снят.
- Каждая колонка обведена рамкой, колонка в фокусе отличается ею же.
- Возврат влево ставит курсор на элемент, с которого человек ушёл вглубь.
- Файл секретов не перезаписывается целиком: меняется только нужный ключ, чужие
  записи и комментарии сохраняются.

## [0.3.0]

Консольный интерфейс вместо команд, которые нужно помнить.

- Доменные пакеты эмитируют события вместо печати; построчный вывод остаётся
  подписчиком, интерфейс не поднимается без терминала.
- Каркас на Bubble Tea и вся петля фикса внутри интерфейса.
- Браузер групп, проектов, пайплайнов и джоб с постраничным обходом и кэшем.
- Проводник по типичным поломкам: токен, Docker, кэш, секреты, SSH-ключ, `extends` —
  экраны с вводом вместо выхода с ошибкой.
- Палитра под любой фон терминала, ширина в графемах, экран помощи, восстановление
  терминала после паники.

## [0.2.0]

Петля отладки: упало → зашёл → починил → проверил начисто → забрал патч.

- Запуск без ручной подготовки: токен, кэш и образ подбираются сами, допущения
  печатаются баннером.
- Код джобы достаётся без обязательного локального клона; токен не попадает ни в
  `.git/config`, ни в `ps`.
- Файловые переменные, переменные пайплайна и `environment_scope` доезжают до
  контейнера, как в настоящей джобе.
- Перезапуск шага, чистый прогон в свежем контейнере и перенос правок в свой
  репозиторий одним коммитом.

## [0.1.0]

Первая работающая версия: по ссылке на упавшую джобу — шелл в контейнере.

- Разбор ссылки, токен из окружения или конфига по хосту, метаданные через GitLab API
  за интерфейсом `Provider`.
- Сборка окружения: предопределённые `CI_*`, переменные проекта и группы, локальные
  секреты для маскированных значений.
- Контейнер того же образа с кодом на нужном коммите, прогон шагов до упавшего и
  интерактивный шелл на месте сбоя.
